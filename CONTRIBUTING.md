# Publishing workflow

The changelog is generated from releases in the private Schedule-X Premium repository.

- Include customer-relevant features, bug fixes, dependency updates, and breaking changes.
- Exclude formatting, tests, CI, refactors, release mechanics, and other internal maintenance.
- Rewrite terse commit subjects in clear customer-facing language.
- Never copy source code, private issue details, internal URLs, or credentials into this repository.
- Publish changes through pull requests. Automation must never merge its own pull requests.
